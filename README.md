# Модульний контроль 1: Вступ до мобільної розробки

**Дисципліна:** Програмування для мобільних платформ
**Студент:** Кононенко Максим Русланович, ІК-41

## Опис проєкту
Цей репозиторій містить виконання практичної модульного контролю №1. Проєкт об'єднує 4 практичні завдання в один Flutter-застосунок зі спільним головним меню для зручної демонстрації під час запису екрану.

### Реалізовані завдання:
1. **Основи Dart (Класи та колекції):** Ієрархія класів для моделювання бібліотеки (`LibraryItem`, `Book`, `Magazine`, `Library`), фільтрація та пошук, відображення результатів у центрованому `ListView`.
2. **Власний Stateless-віджет:** Створено віджет `RatingBadge`, який відображає рейтинг та динамічно змінює колір іконки зірки відповідно до значення (>= 4.0 — зелений, >= 2.5 — оранжевий, інакше — червоний).
3. **State Management та навігація:** Реалізовано `HomeScreen` із лічильником `setState()` та `DetailScreen`. Передача стану лічильника здійснюється виключно через конструктор під час навігації за допомогою `Navigator.push`.
4. **Асинхронний код:** Клас `WeatherService` імітує отримання даних про погоду за допомогою `Future` та потокових оновлень температури через `Stream`. У UI реалізовано обробку завантаження та помилок.
